# RocoWordle

一款基于《精灵图鉴》的猜谜小游戏——系统随机选定一只精灵，玩家通过搜索提交猜测，根据 7 个字段的三态反馈（绿/黄/红）逐步锁定答案。

## 玩法

- 从精灵图鉴中随机选定一只精灵作为答案
- 输入名称或拼音搜索精灵，点击「猜测」提交
- 系统对 8 个字段返回反馈：
  - 🟢 绿 = 正确
  - 🟡 黄 = 近似
  - 🔴 红 = 错误
- 8 次机会、2 次提示，猜中即胜利

## 字段与规则

| 字段 | 绿色条件 | 黄色条件 |
|---|---|---|
| 名称 | 内容相同 | 无 |
| 阶级 | 数值相等 | 无 |
| 星光值 | 数值相等（红色时▲偏高/▼偏低） | 无 |
| 属性 | 属性集合相同（顺序无关） | 有交集但不完全相同 |
| 蛋组 | 蛋组集合相同（顺序无关） | 有交集但不完全相同 |
| 异色 | 同为✔或同为空 | 无 |
| 首领化 | 同为✔或同为空 | 无 |
| 多形态 | 同为✔或同为空 | 无 |

## 搜索功能

- 名称子串匹配（如搜「守护」可找到「书卷守护」）
- 拼音全拼 / 首字母匹配（如 `dimo` 或 `dm` → 迪莫）
- 同谱系扩展：搜索会带出同初始形态的其他阶级精灵
