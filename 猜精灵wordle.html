近似判定原则

🟢 属性近似规则

属性完全相同（顺序无关）→ 绿；只要有一个属性相同 → 黄；完全不同 → 红。

示例：「草 地」vs「水 草」→ 黄；「草 地」vs「地 草」→ 绿；「草」vs「水」→ 红。

🟡 蛋组近似规则

蛋组完全相同（顺序无关）→ 绿；只要有一个蛋组相同 → 黄；完全不同 → 红。

「无法孵蛋」特殊：双方都为「无法孵蛋」→ 绿；否则只要有「无法孵蛋」参与 → 红（不做近似）。

示例：「天空 巨灵」vs「巨灵 动物」→ 黄；「动物」vs「动物 拟人」→ 黄。

⚪ 阶级 / 首领化 / 多形态

完全相同 → 绿；否则 → 红。这三个字段无黄色近似。

🟣 星光值

完全相同 → 绿；猜测值偏高显示 ▲，偏低显示 ▼。
