近似判定原则

🟢 属性近似规则

属性完全相同（顺序无关）→ 绿；只要有一个属性相同 → 黄；完全不同 → 红。

示例：「草 地」vs「水 草」→ 黄；「草 地」vs「地 草」→ 绿；「草」vs「水」→ 红。

🟡 蛋组近似规则

蛋组完全相同（顺序无关）→ 绿；只要有一个蛋组相同 → 黄；完全不同 → 红。

「无法孵蛋」特殊：双方都为「无法孵蛋」→ 绿；否则只要有「无法孵蛋」参与 → 红（不做近似）。

示例：「天空 巨灵」vs「巨灵 动物」→ 黄；「动物」vs「动物 拟人」→ 黄。

⚪ 阶级 / 异色 / 首领化 / 多形态

完全相同 → 绿；否则 → 红。这四个字段无黄色近似。

猜精灵 Wordle · 游戏规则

基本玩法

系统从精灵图鉴中随机抽取一只精灵作为答案。你需要根据每次猜测的颜色反馈，在有限的次数内猜出正确答案。

操作说明

  • 在搜索框中输入精灵名称，下方会列出匹配结果。
  • 选中一只精灵后点击「猜测」，系统会比较该精灵与答案的各项特征，并以颜色反馈。

颜色反馈含义

  • 绿 猜测值与答案完全一致
  • 黄 猜测值与答案「相近」但不完全相同
  • 红 猜测值与答案完全不同

比较字段（共 7 项）

字段说明
阶级精灵的形态阶级（1 / 2 / 3 ）
星光值精灵的星光值
属性精灵的属性（注：多形态精灵按默认形态属性计算）
蛋组精灵的蛋组分类
异色该精灵是否有异色形态
首领化当前形态是否可以首领化
多形态是否拥有多形态，如鸭吉吉（蓬松的样子）

各字段判定规则

属性：属性集合完全相同（顺序无关）→ 绿；只要有一个属性相同 → 黄；完全不同 → 红。
示例：「草 地」vs「水 草」→ 黄；「草 地」vs「地 草」→ 绿；「草」vs「水」→ 红。

蛋组：蛋组集合完全相同（顺序无关）→ 绿；只要有一个蛋组相同 → 黄；完全不同 → 红。
特殊规则「无法孵蛋」：双方都为「无法孵蛋」→ 绿；只要有「无法孵蛋」参与且不一致 → 红（不做近似）。
示例：「天空 巨灵」vs「巨灵 动物」→ 黄；「动物」vs「动物 拟人」→ 黄。

星光值：完全相同 → 绿；猜测值偏高显示 ▲，偏低显示 ▼。

阶级 / 异色 / 首领化 / 多形态：完全相同 → 绿；否则 → 红。这四个字段无黄色近似。

游戏配额

胜利与失败

  • 8 次机会耗尽仍未全部猜中 → 失败

  • 已提示的字段不会重复揭示；已在猜测中确认（绿色）的字段也不再提示。
